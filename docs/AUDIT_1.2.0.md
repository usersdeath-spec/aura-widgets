# Audit — 1.2.0

Six automated gates plus a manual pass over the things no gate covers.

## Gates

| Gate | Scope | Result |
|---|---|---|
| `static_check` | Structure, imports, exhaustive `when`, Compose delegates, const, duplicates | 78 files, 0 |
| `deep_check` | Symbol resolution, arity, named args, missing required args | 1,152 symbols, 0 |
| `module_check` | Dependency declaration, feature-to-feature layering | 11 modules, 0 |

One command: `sh tools/check_all.sh`

## Findings this round

**1. `java.time` without desugaring — `:widget` and `:feature:editor`.** Both use `LocalDateTime`,
`ZoneId`, `Duration` and `Instant` at minSdk 26. AGP needs *both* `isCoreLibraryDesugaringEnabled`
and the `coreLibraryDesugaring` dependency; either alone silently does nothing, so the failure is a
runtime crash on an older device rather than a build error. Fixed in both, and now gated.

**2. R8 would strip 578 classes from the release build.** The 572 generated providers plus
`PrismTallProvider`, `PrismLargeProvider`, `PrismBannerProvider`, `PinResultReceiver` and
`WidgetConfigureActivity` are named only as manifest strings, so R8 full mode sees no reference and
removes them. **The widget picker would have been full in debug and empty in release** — invisible
until the build you actually ship. Keeps added, and now gated.

**3. SDK detection.** `local.properties` is machine-specific and gitignored, so every fresh extract
failed with "SDK location not found" before compiling anything. `settings.gradle.kts` now detects
the SDK and writes the file, only when absent.

## Manual checks with no finding

- Every class named in a manifest exists in source.
- Every module using Compose declares the compiler plugin; every module using annotations declares KSP.
- Every module declares a namespace; `minSdk` is 26 everywhere.
- `:app` declares a dependency on every module it imports from.
- AGP 8.7.3 / Kotlin 2.1.0 / KSP 2.1.0-1.0.29 / Gradle 8.11.1 / JVM 17 are mutually compatible.
- Room's `schemaLocation` is declared in the module holding the `@Database`, not in `:app`.
- 572 layouts, 572 provider XMLs, 572 receivers, 572 classes — all four counts match, no duplicates.

## Two checker bugs found and fixed

Worth recording, because a silent checker is worse than no checker.

- `static_check` whitelisted `BuildConfig` as "generated by AGP". True of `R`; **false of
  `BuildConfig`**, which AGP 8 generates only on request — so the whitelist hid a real error for a
  whole build cycle. It now inspects the module's build file.
- `xml_check` computed the R8 findings correctly and never printed them, because the new issue kind
  was missing from the print order. Same bug I had already fixed in `static_check` and did not
  generalise. Both files now fail loudly on an unregistered kind.

## What the gates still cannot do

They do not type-check. A wrong type passed to a correctly-named parameter compiles cleanly in their
view and fails in Kotlin's. That is the gap between "gates green" and "compiles", and the reason
these reports never claim the build will succeed.
